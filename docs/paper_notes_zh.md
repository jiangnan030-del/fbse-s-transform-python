# 傅里叶-贝塞尔域 S 变换方法笔记（中文整理）

本文档根据当前项目页内容整理，用于给仓库保留一份中文方法说明，便于后续代码实现、论文复现和公式推导统一参照。

## 1. 研究背景：传统时频分析的局限

在非平稳信号处理中，时频分析的核心任务是揭示频率成分随时间的演化规律。

传统短时傅里叶变换（STFT）虽然实现简单，但存在固定窗长带来的固有矛盾：

- 窗长较短时，时间分辨率较高，但频率分辨率较差；
- 窗长较长时，频率分辨率较高，但时间分辨率较差。

除此之外，STFT 在频域上还会出现能量扩散、主瓣展宽和旁瓣泄漏等问题，导致：

- 时频图模糊；
- 瞬时频率脊线不清晰；
- 冗余能量较多；
- 精确定位困难。

已有的同步压缩变换、同步提取变换等方法能够改善能量聚集性，但通常伴随：

- 相位导数计算；
- 复杂的重排过程；
- 对噪声较敏感；
- 参数调节成本高。

因此，需要一种结构清晰、实现可控、同时具备能量聚焦能力的新方法。

## 2. 傅里叶-贝塞尔级数的优势

傅里叶-贝塞尔级数（FBSE）使用贝塞尔函数而不是传统正弦余弦作为展开基。

其基本特点包括：

- 使用零阶贝塞尔函数 \(J_0\) 的零点作为特征频率位置；
- 能够将信号表示为一组贝塞尔基函数的线性组合；
- 对瞬态、冲击、非平稳特征具有较好的适配性；
- 在机械振动、语音和生物电等信号中具有潜在优势。

但 FBSE 本身主要提供频域表示，时间定位能力不足，因此需要与时频分析框架结合。

## 3. 傅里叶-贝塞尔域 S 变换的核心思想

傅里叶-贝塞尔域 S 变换（FBSE-ST）的思想是：

1. 先把信号投影到傅里叶-贝塞尔域，得到较稀疏、较集中的系数表示；
2. 在贝塞尔频率轴上构造一个频率自适应高斯窗矩阵；
3. 对系数域矩阵进行加权和聚焦；
4. 再通过贝塞尔基映射回时域，得到最终时频分布。

与传统 S 变换类似，其目标是在低频处使用更宽的分析窗，在高频处使用更窄的分析窗，从而获得更合理的时频分辨率分配。

## 4. 算法步骤

### 第 1 步：计算零阶贝塞尔函数零点

计算 \(J_0(x)\) 的前若干个正零点 \(\alpha_m\)。这些零点在本方法中对应一组离散的贝塞尔频率位置。

当前仓库中采用牛顿迭代法求解，并利用：

\[
J_0'(x) = -J_1(x)
\]

来进行迭代更新。

### 第 2 步：构造贝塞尔基矩阵并计算 FBSE 系数

对于长度为 \(N\) 的离散信号 \(x[n]\)，构造贝塞尔基矩阵：

\[
D_{m,n} = J_0\left(\frac{\alpha_m}{N} n\right)
\]

并据此计算 FBSE 系数：

\[
a_m = \frac{2}{N^2 J_1^2(\alpha_m)} \sum_{n=1}^{N} n x[n] J_0\left(\frac{\alpha_m}{N} n\right)
\]

这些系数表示信号在傅里叶-贝塞尔域上的投影结果。

### 第 3 步：构造频率自适应高斯窗并进行系数域加权

根据贝塞尔零点建立一条伪频率轴。当前实现中，伪频率可写为：

\[
f_m \propto \alpha_m
\]

并可进一步标准化到 \((0, 1]\) 区间。

随后，为每个频率位置定义自适应窗宽：

\[
\sigma_m = \frac{c}{f_m}
\]

其中 \(c\) 是控制窗宽尺度的参数。

再构造高斯加权矩阵：

\[
G_{m,k} = \frac{1}{\sqrt{2\pi}\sigma_m}
\exp\left(-\frac{(f_k - f_m)^2}{2\sigma_m^2}\right)
\]

同时，根据 FBSE 系数向量构造 Toeplitz 矩阵 \(T\)，并进行逐元素加权：

\[
W = T \odot G
\]

其中 \(\odot\) 表示 Hadamard 逐元素乘积。

这一阶段的目标是将泄漏到邻近频率位置的能量重新聚集到中心频率附近。

### 第 4 步：时频重建

将加权后的系数域矩阵通过贝塞尔基矩阵映射回时频平面：

\[
Z = W D
\]

并进一步得到：

- 幅值时频图：\( |Z| \)
- 能量时频图：\( |Z|^2 \)

最终的能量图可用于和 STFT 结果进行可视化对比及定量评价。

## 6. 后续可继续推进的方向

后续建议重点包括：

1. 严格核对目标文献中的离散推导过程；
2. 明确 Toeplitz 构造的精确定义；
3. 检查重建阶段是否需要转置、共轭或额外归一化；
4. 引入更系统的定量指标，如：
   - 能量集中度；
   - Rényi 熵；
   - 稀疏性指标；
   - 与 STFT 的对比优势指标；
5. 进一步在真实实验信号上验证方法表现。
